# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in **dz-sandbox** a welcoming, respectful, and harassment-free experience for everyone regardless of background, experience level, language (Arabic, Tamazight, French, English), or identity.

## Expected Behavior

- Be constructive and patient in code reviews and fixture discussions.
- Respect maintainers' requests regarding official documentation evidence (`docs/SPEC_STATUS.md`) and security boundaries.
- Never upload private bank/merchant PDFs or confidential credentials to public issues or PRs; share sanitized, redacted JSON schemas or field tables instead.

## Unacceptable Behavior

- Harassment, personal attacks, trolling, or discriminatory remarks.
- Submitting real merchant API keys, PANs/card numbers, or customer PII.
- Attempting to pass unverified API guesses as verified specifications.

## Enforcement

Instances of abusive or unacceptable behavior may be reported via a private message or repository security/maintainer contact. All complaints will be reviewed fairly and confidentially.
