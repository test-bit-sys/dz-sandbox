# Support for dz-sandbox

Thank you for using **dz-sandbox**! Here is how to find help or ask questions:

## 1. Documentation & Guides
Before opening an issue, check the bundled guides:
- [Common Integration Bugs](./docs/guides/common-integration-bugs.md) — Walkthroughs of 9 real-world payment and delivery failure modes.
- [Specification Status Ledger](./docs/SPEC_STATUS.md) — What is verified vs. simulated for each provider.
- [Scenario Catalog](./docs/scenarios.md) — Complete list of built-in failure scenarios.
- [Threat Model & Security Defaults](./docs/THREAT_MODEL.md) — Security boundaries, SSRF protection, and local loopback defaults.

## 2. Asking Questions & Community Discussion
For general questions, architecture discussions, or sharing integration tips:
- Use [GitHub Discussions](https://github.com/[OWNER]/dz-sandbox/discussions).

## 3. Reporting Bugs & Requesting Features
- If you encountered unexpected behavior or a discrepancy against official provider behavior:
  Open a [Bug Report](https://github.com/[OWNER]/dz-sandbox/issues/new?template=bug_report.yml).
- To request a new Algerian payment or courier provider:
  Open a [Provider Request](https://github.com/[OWNER]/dz-sandbox/issues/new?template=new_provider_request.yml).
- To contribute recorded test fixtures:
  Read [docs/CONTRIBUTING-FIXTURES.md](./docs/CONTRIBUTING-FIXTURES.md) and open a [Fixture Contribution](https://github.com/[OWNER]/dz-sandbox/issues/new?template=fixture_contribution.yml).

## 4. Security Vulnerabilities
Please do **not** report security vulnerabilities through public GitHub issues or discussions. Follow the instructions in [SECURITY.md](./SECURITY.md) to report privately via GitHub Private Vulnerability Reporting.
