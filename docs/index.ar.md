# توثيق dz-sandbox (العربية - RTL)

**اختبر ما يفشل، لا ما ينجح فقط.**

بيئة محاكاة محلية وحتمية تعمل بالكامل **دون إنترنت** لاختبار بوابات الدفع والتوصيل في الجزائر (**Chargily Pay v2**، **SATIM**، **Yalidine**) مع التبديل الفوري بين سيناريوهات الأعطال دون حساب تاجر أو بطاقات حقيقية.

- [دليل التسجيل وإزالة الأسرار (CAPTURE_GUIDE)](./CAPTURE_GUIDE.md) — استخدام `dz-sandbox record` و`fixtures validate`.
- [المساهمة ببيانات حقيقية (CONTRIBUTING-FIXTURES)](./CONTRIBUTING-FIXTURES.md) — قائمة الفحص الإلزامية قبل فتح PR.
- [أخطاء التكامل الشائعة (9 أدلة عملية)](./guides/common-integration-bugs.md) — كيف تعيد إنتاج أشهر الأعطال وتصلحها.
- [كتالوج السيناريوهات (Scenarios)](./scenarios.md) — قائمة الـ 27 سيناريو المدمجة.
- [نموذج التهديدات الأمنية (THREAT_MODEL)](./THREAT_MODEL.md) — حماية SSRF وعزل المسارات ومصادقة لوحة التحكم.
